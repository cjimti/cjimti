## MCP Toolkit

A composable suite of Model Context Protocol servers for data platform integration, all in Go:

- **[mcp-data-platform](https://github.com/txn2/mcp-data-platform)** - Semantic data platform server with bidirectional cross-injection across tools.
- **[mcp-datahub](https://github.com/txn2/mcp-datahub)** - DataHub metadata access for AI assistants.
- **[mcp-trino](https://github.com/txn2/mcp-trino)** - Trino-backed warehouse query and exploration.
- **[mcp-s3](https://github.com/txn2/mcp-s3)** - S3 and S3-compatible object storage access.

I'm commercializing this work as **[Plexara](https://plexara.io)**, AI integration for companies running bespoke data platforms.
